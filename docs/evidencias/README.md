# Evidencias del proyecto

Guarda aquí las capturas y registros que respaldan los Checkpoints 1 y 2 y la Guía 09:

- `firebase-inicializado.png`: consola con «Firebase conectado: …».
- `app-citas.png`: pantalla de citas con datos de demostración.
- `talkback.png`: recorrido con TalkBack o escalado de texto.
- `checkpoint-1.pdf`: lista de verificación firmada por el equipo revisor.
- `auth-proveedor.png`: Correo electrónico/contraseña habilitado en Firebase.
- `auth-registro.png`: cuenta ficticia creada desde la app.
- `auth-inicio-sesion.png`: inicio de sesión con la cuenta de prueba.
- `auth-sesion-persistente.png`: sesión restaurada tras reiniciar la app.
- `auth-pruebas.txt`: salida de las pruebas de validadores y sesión.
- `auth-accesibilidad.png`: formulario con escala de texto ampliada; documenta
  TalkBack en el checklist del Checkpoint 2.

No incorpores datos personales ni de salud reales. Los archivos grandes de video
están excluidos por `.gitignore`; compártelos por enlace.
